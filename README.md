# TerraformProject
Hosting a static webpage on AWS

Steps to use the IaC> 

1. Open PowerShell in admin mode.

2. Navigate to the folder of the Terraform project.

3. Run commands “terraform init”, “terraform plan”, and “terraform apply.”

4. Terraform creates AWS resources.

5. Get HTTPS link via output.

6. Test if the HTTPS link works in a browser.
